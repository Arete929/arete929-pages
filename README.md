# arete929-pages — 구글 주소를 거치지 않는 «자체 페이지» 모음

`a.arete929.kr` … `z.arete929.kr` 중 마이아레테에서 **«자체 페이지»** 로 고른 칸은, 이 저장소의 **글자 폴더**(`a/` … `z/`)를 그 주소 그대로 보여 줍니다.
(구글 주소 `script.google.com` 을 거치지 않아서 **만 13세 미만 구글 계정 차단이 걸리지 않습니다.**)

```
arete929-pages/
  a/index.html      ← a.arete929.kr 로 열리는 화면
  b/…               ← b.arete929.kr
  …
  _template-student-app/   ← 새 학생용 앱을 만들 때 복사하는 틀 (정적 화면 + 앱스크립트 API)
```

## 새 학생용 앱 만드는 순서
1. `_template-student-app/` 폴더를 통째로 복사해서 빈 글자 폴더 이름으로 바꾼다 (예: `e/`).
2. `index.html` 맨 위의 `API` 주소를 앱스크립트 API 웹앱 주소로 바꾼다. 화면 내용을 앱에 맞게 고친다.
3. 앱스크립트 쪽은 `gas-api-sample.js` 를 참고해 **JSON 만 주고받는 API** 로 만든다 (HTML 을 내보내지 않는다). 배포는 «실행: 나 · 액세스: 모든 사용자».
4. 이 저장소에 커밋·푸시 → 1~2분 뒤 GitHub Pages 에 반영.
5. 마이아레테 › 설정 › 주소 칸 a–z 에서 그 글자 칸을 **«자체 페이지»** 로 저장.
6. `https://e.arete929.kr` 로 확인. (워커가 60초쯤 기억하므로 바로 안 바뀌면 잠깐 기다린다.)

## 왜 이렇게 하나
- 학생 폰에 만 13세 미만 구글 계정이 로그인돼 있으면 **구글 주소를 여는 순간** 구글이 막는다 — 앱 코드로는 못 고친다.
- 화면을 우리 도메인(GitHub Pages)에 두고, 앱스크립트는 **쿠키 없이** 부르는 API 로만 쓰면 구글 계정이 끼지 않아 막히지 않는다.
- 브라우저가 `fetch` 를 보낼 때 구글 쿠키를 안 보내려면: `credentials` 를 쓰지 말고(기본값), POST 는 `Content-Type: text/plain;charset=utf-8` 로 보낸다(사전 확인 요청 방지).

## 지킬 것
- 이 저장소는 **공개**다. 학생 이름·명단·열쇠·비밀번호를 파일에 넣지 않는다. 데이터는 전부 앱스크립트 API 가 준다.
- `alert()` `confirm()` `prompt()` 를 쓰지 않는다(자체 대화상자·토스트).
- 화면 맨 아래에 버전 바닥글(앱 제목 · 버전 · 배포 시각 · ⓒKIMJINHO)을 넣는다.
